GAVIN BUTTS — COLORFUL ACADEMIC WEBSITE

Unzip gavinbutts-website.zip, then open index.html to preview it locally.

UPDATE YOUR EXISTING GITHUB WEBSITE
1. Open github.com/GavinButts/gavinbutts.github.io.
2. Choose Add file > Upload files.
3. Upload index.html, research.html, teaching.html, education.html,
   styles.css, and clicks.js directly to the repository root.
4. Keep your existing gavin-photo.jpg and CNAME file. The ZIP includes the
   photograph if you need it again.
5. Commit directly to main with the message "Refresh website design".
6. Wait for GitHub Pages to publish, then refresh your website.
   On Mac, Command-Shift-R reloads cached styles if needed.

Upload the individual files, not the ZIP or an enclosing folder.
No changes to DNS or HTTPS settings are required.

The four pages share styles.css and clicks.js. Page navigation and content
work without JavaScript. Hover motion and the colorful click effect respect
reduced-motion preferences. Decorative math symbols are hidden from screen readers.
